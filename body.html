Adds an explanation page to every unit: what the unit is about, the key ideas in a table, worked examples, the mistakes learners most often make, and how to work through the unit. Answer keys always give the reason or method behind each answer.

9 · Settings

How many questions each exercise sheet should contain, and which variant of the pack to generate.

Sets the body text size on every sheet — on screen, in print and in the Word file. Headings, tables and instruction boxes scale with it automatically. The default is 12pt; larger sizes suit lower grades but fit less on each sheet, so the page count will rise.

Change the seed to generate a different version of the same pack — useful for Test A / Test B. The same seed always produces exactly the same pack, so a student copy and a teacher copy printed with the same seed will match question for question.
