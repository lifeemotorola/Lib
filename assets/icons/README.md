# Application icon

The favicon and installable-app icons use the Liberia flag map requested for
the platform. They are resized derivatives of **Flag map of Liberia** by
Wikimedia Commons user Darwinek, licensed under
[CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/).

Source: <https://commons.wikimedia.org/wiki/File:Flag_map_of_Liberia.svg>

- `liberia-map.png` — source-sized transparent PNG used to derive the icons
- `favicon-48.png` — browser tab icon, also inlined by `build.sh`
- `apple-touch-icon.png` — iPhone/iPad home-screen icon
- `icon-192.png` and `icon-512.png` — Android and desktop PWA icons
- `icon-maskable-512.png` — safe-zone version for shaped Android launchers
