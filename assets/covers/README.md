# Subject cover artwork

These 16 PNG files are the built-in, subject-matched cover backgrounds. `build.sh`
inlines them into `index.html`, so they continue to work offline. Each image is
480 × 640 px, converted to an indexed PNG to keep the single-file app practical.

The 15 curriculum covers (`en`, `pho`, … `li`) are photographs retrieved from
the web, except `pho.png` (Phonics), which is an **AI-generated image** — and
the single `wa.png` cover used by **every** subject in the WASSCE session is
also an **AI-generated image** (modelled on the real WAEC objective-test answer
sheet) — see the second table below.

The source images were retrieved from the web and cropped/downsized for use as

## WASSCE session artwork

`wa.png` is **generated by an image model**, so there is no upstream photographer
or licence to clear, just like the Phonics cover (`pho.png`). It is modelled on the authentic WAEC WASSCE objective-test
**answer sheet / booklet cover** — the document candidates shade with a pencil:
a barcode timing strip, the printed "Name / Examination / Subject / Year / Paper"
form, and the OMR subject-code and index-number grids. The fields are deliberately
left blank and there is no readable body text, so nothing in the artwork could be
mistaken for an examination question, a worked answer or a candidate's details.

| File | Used by | Depicts |
|---|---|---|
| `wa.png` | **Every** WASSCE subject (Mathematics, English Language, History, Biology, Chemistry, Physics, Economics, Geography, Agriculture, Literature, Christian Studies) | A blank WAEC WASSCE answer sheet: barcode strip, candidate form fields and shaded OMR answer grids |

The WASSCE track deliberately shares this one cover instead of giving each subject
its own picture: it is the real examination cover page, so it looks right for every
WASSCE pack whatever the subject. `activeCoverBg()` in `app.js` returns `wa.png` for
any subject whose registry entry carries the `wa` flag. The earlier per-subject
generated scenes (the mathematics chalkboard, English desk, history map and biology
bench `wma/wen/whis/wbio.png`) were removed at the school's request.

The artwork is only atmosphere: the cover renderer veils it behind the paper
(`COVER.bgFade`, default 62%), and it carries no text a learner could read or rely on.

## Replacing an image

When replacing an image, keep the subject filename and run `bash build.sh`. For the
14 web-sourced photographic covers, verify the source's license and attribution
requirements before redistribution; the two AI-generated covers (`pho.png`,
`wa.png`) have no upstream licence to clear.

`build.sh` quotes every key in `window.SUBJECT_COVER_ART` so the mapping is uniform
regardless of the id.
